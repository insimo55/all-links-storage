## All Links – статический каталог ссылок с редиректами

Мини-сайт для размещения на GitHub Pages. Позволяет:

- интерактивные карточки ссылок (открытие в новой вкладке или текущей)
- загрузку ссылок из `links.json`
- поддержку тёмной/светлой темы с переключателем
- «красивые» короткие пути вида `/slug` (работает на GitHub Pages через `404.html`)

### Быстрый старт

1) Отредактируйте `links.json` — добавьте свои ссылки. Поля:

```json
{
  "title": "Название",
  "description": "Описание (необязательно)",
  "url": "https://target",
  "slug": "короткий-идентификатор",
  "icon": "https://.../icon.svg (необязательно)",
  "color": "#RRGGBB (необязательно)",
  "target": "blank | self" // blank — в новой вкладке, self — в этой же
}
```

2) Откройте `index.html` локально (или задеплойте на Pages) и проверьте.

### Публикация на GitHub Pages

- Для репозитория-страницы: Settings → Pages → Source: `Deploy from a branch`, Branch: `main` (`/root`).
- Для пользовательского домена настроить CNAME при необходимости.

`404.html` обеспечивает SPA-редирект: при заходе на `/repo/some-slug` будет предпринята попытка найти `some-slug` в `links.json` и выполнить перенаправление. Если не найдено — произойдёт возврат на главную с сообщением.

### Переадресация по путям и параметрам

- Путь: `/slug` — если `slug` найден, откроется соответствующий `url`.
- Параметры: `?to=slug&open=blank|self` — принудительное открытие по параметрам.

### Разработка

Сайт статический, достаточно любой статики/хостинга. Никаких зависимостей.
